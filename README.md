# Bebralingo

Тренажёр слепой печати для Android на Kotlin и Jetpack Compose.

## Что внутри

- **Путь обучения** — 5 блоков уроков (основной ряд, верхний, нижний, цифры и знаки, тексты) с последовательной разблокировкой.
- **Тренировка** — посимвольная подсветка, живой CPM, точность, XP, вибрация и тряска при ошибке.
- **Спринты** — 30 секунд, 1 минута, 3 минуты на случайных текстах.
- **Достижения** — 6 наград за скорость, точность и серию дней.
- **Гайд** — раскладка ЙЦУКЕН с зонами пальцев, посадка и советы.
- **Прогресс** хранится локально в DataStore: XP, серия дней, пройденные уроки, рекорды, достижения.

## Сборка

Требуются JDK 17+ и Android SDK (compileSdk 34).

```bash
./gradlew :app:assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Структура

```
app/src/main/java/com/bebralingo/
├── data/        # DataStore, контент уроков, достижения
├── model/       # доменные модели и typealias-ы
├── navigation/  # навигация и фабрика ViewModel
└── ui/          # экраны, компоненты, тема
```
